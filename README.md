# 💉 Lucia Aesthetic & Dermatology Clinic — Dubai Flagship
> **Jumeirah Luxury Web Experience**: Swiss medical precision meets 5-star Arabian hospitality. Designed for high-net-worth VIPs, celebrity clientele, and international cosmetic tourism.

---

## 🏛️ Project Overview
* **Client**: Lucia Aesthetic & Dermatology Clinic (Villa 323, Jumeirah Beach Road, Dubai)
* **Founder & Medical Director**: Dr. Radmila Lukian (European board-certified dermatologist, CNN medical contributor)
* **Distinction**: Destination for global icons including Naomi Campbell, Eva Longoria, Lindsay Lohan, and Huda Kattan.
* **Technology Stack**: React 19, TypeScript, Vite 6, Tailwind CSS v4, Lucide Icons.

---

## 🎨 Design System & Brand Palette
* **Alabaster White (`#FCFCF9`)**: Primary sterile yet warm clinical ground.
* **Cashmere Warm Stone (`#EFEBE4`)**: Secondary card and section backgrounds.
* **Deep Slate Espresso (`#1A1918`)**: High-contrast, non-harsh luxury typography.
* **Rosé Bronze (`#B99882`)**: Subtle metallic accent for badges, icons, and highlights.
* **Typography**:
  * Display: *Cormorant Garamond* (Italian/French editorial serif).
  * Body & Specs: *Inter* (Swiss precision sans-serif).

---

## ✨ Key Features & Interactive Architecture
1. **The Red Carpet Roster**: Editorial celebrity social proof featuring verified quotes from Naomi Campbell, Eva Longoria, and Huda Kattan.
2. **Signature Treatment Directory**: 4 curated medical pillars (Facial Architecture, Laser Rejuvenation, Visiting Masters, Longevity Medicine) with interactive modal triggers.
3. **Visiting Masters Spotlight**: Dedicated residency showcase for Beverly Hills rhinoplasty specialist **Dr. Raj Kanodia**.
4. **Founder Profile**: Editorial portrait and philosophy statement of Dr. Radmila Lukian with European board credentials.
5. **Interactive VIP Concierge Modal**:
   - Treatment selector with instant discipline filtering.
   - Private suite vs. In-villa/Yacht visit appointment setting.
   - 1-tap pre-filled WhatsApp VIP concierge dispatch.
6. **Ultra-Responsive & Zero CLS**: 100% responsive, sub-second load time, zero layout shift.

## 🚀 Running Locally

```bash
cd dubai/lucia-clinic
npm install
npm run dev
```

Build for production:
```bash
npm run build
npm run preview
```
